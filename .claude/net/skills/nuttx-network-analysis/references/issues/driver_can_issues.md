## 1. CAN 驱动/协议栈导致的 Crash

**特征**：内存保护异常或其他 trap，调用栈涉及 CAN 相关函数

**排查思路**（按可能性排序）：

### 1.1 SocketCAN 协议栈多核竞争

- 多核同时操作同一 CAN 连接
- IOB 在核间传递时的竞争条件
- 网络全局锁使用不当

### 1.2 CAN 驱动代码 bug

- 空指针解引用
- TX/RX 回调中的越界访问
- 中断上下文中的非法内存访问

### 1.3 IOB 生命周期管理错误

- IOB 重复释放（double-free）
- IOB 释放后继续使用（use-after-free）
- IOB 未正确传递导致泄漏

### 1.4 CAN 硬件寄存器配置错误

- Message RAM 地址/大小配置错误
- FIFO 溢出未正确处理
- 中断使能/清除时序问题

## 2. CAN TX 失败

**特征**：sendmsg 返回负数值，errno 可能为 ENOBUFS、EAGAIN、EIO 等

**排查思路**：

### 2.1 驱动层问题

- TX FIFO/Queue 满（检查硬件 TX 状态寄存器）
- TX 事件 FIFO 溢出未处理
- 驱动发送函数返回错误码分析

### 2.2 硬件配置

- CAN 波特率/时序配置是否正确
- TX Buffer 元素大小是否匹配 CAN FD 数据长度
- Message RAM 中 TX 区域配置是否正确

### 2.3 协议栈问题

- IOB 分配失败
- 网络设备未正确 up
- TX 通知未能触发驱动发送

### 2.4 总线状态

- CAN 总线无其他节点（无 ACK）
- Bus-Off 状态未恢复
- 错误计数器超限

## 3. CAN RX 异常

**特征**：收到的帧数据内容错乱，或完全收不到报文

**排查思路**：

### 3.1 驱动层问题

- 从 Message RAM 读取数据的逻辑是否正确
- RX FIFO 溢出导致丢帧
- RX 中断处理函数中的 bug

### 3.2 硬件配置

- RX Filter 配置是否正确（标准/扩展 ID）
- Message RAM 中 RX 区域配置
- RX FIFO 水位设置与中断触发条件

### 3.3 协议栈问题

- 收包处理过程中的数据拷贝错误
- CAN 过滤器（socket 选项）配置不当
- 多 socket 绑定同一设备时的分发逻辑

### 3.4 多核竞争

- RX 中断与应用层 recvmsg 的竞争
- IOB 链表操作的原子性问题

## 4. CAN 控制器初始化 assert 无法启动

**特征**：烧录后无法启动，在 CAN ifup 时进入 assert，高概率复现

**原理**：CAN 控制器初始化涉及 Message RAM 配置和模式切换，这些操作有超时限制。多核场景下如果多个核同时 ifup 同一控制器资源，可能导致竞争。

**典型案例**：VELAFORCAR-12947

**排查思路**：
1. 检查 CAN 驱动 ifup 时 MRAM 初始化和控制寄存器配置时序
2. 检查多核场景下 CAN 控制器资源是否存在竞争
3. 检查 assert 触发点是否在配置超时或模式切换失败处


## 5. 周期任务 runningtime 超预期（中断负载高）

**特征**：周期任务实际执行时间远超配置周期，中断占用过高

**原理**：CAN 高负载时接收中断频繁触发，如果中断处理或中断下半部排队过长，会抢占周期任务的 CPU 时间。

**典型案例**：VELAFORCAR-13088

**排查思路**：
1. 统计各中断的触发频率和处理耗时
2. 检查 CAN 接收中断是否因高负载导致频繁触发
3. 检查工作队列积压情况
4. 考虑调整中断处理方式或中断亲和性


## 6. BMP 模式中断 work 激活慢

**特征**：BMP 模式下网络负载时中断执行次数比 AMP 少，耗时更长

**原理**：BMP 模式下多核共享调度器，中断 bottom half 可能被其他核的调度实体抢占，导致中断响应延迟增大。

**典型案例**：VELAFORCAR-16171

**排查思路**：
1. 检查中断亲和性配置——中断是否被分配到负载最高的核
2. 检查工作队列调度优先级在 BMP 下是否被抢占
3. 对比 BMP/AMP 的中断响应延迟
4. 检查是否有不必要的锁争用

## 7. BMP 模式 CAN 报文不外发

**特征**：BMP 版本 CAN 报文停止外发

**原理**：BMP 模式下如果 CAN 驱动的全局变量未正确隔离（非 BMP 安全），或者 AMP 遗留的跨核调用在 BMP 下失效，会导致发送路径异常。

**典型案例**：VELAFORCAR-14703

**排查思路**：
1. 检查 CAN 驱动的全局变量是否正确隔离
2. 检查发送路径中是否有 AMP 遗留的跨核调用在 BMP 下失效
3. 确认接口状态和错误计数
4. 检查 TX mailbox 是否已满但无法触发完成中断
