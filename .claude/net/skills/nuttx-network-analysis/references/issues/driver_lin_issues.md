## 1. LIN 调度表执行异常

**特征**：LIN 调度表配置后部分帧未按预期周期发送/接收，或超时报错

**排查步骤**：
1. 检查调度表条目配置（帧 ID、周期、slot 分配）
2. 检查 LIN master 定时器精度是否满足调度要求
3. 检查是否有高优先级任务抢占导致调度延迟
4. 检查 slave 响应超时配置是否合理

---

## 2. LIN 主/从模式切换问题

**特征**：LIN 控制器在 master/slave 模式切换时出现通信中断或状态异常

**排查步骤**：
1. 检查切换时序是否满足总线静默要求
2. 检查切换前是否正确停止当前调度表
3. 检查切换后寄存器配置是否完整重新初始化
4. 检查是否有未完成的帧传输被中断
